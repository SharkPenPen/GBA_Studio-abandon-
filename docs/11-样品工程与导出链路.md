# 11 · 样品工程与导出链路

这份文档记录 **P4：从编辑器一路做到 GBA ROM** 的完整链路，以及样品工程的用法。

---

## 一、一句话流程

```
编辑器排时间轴  →  编译成剧本  →  调现有工具链  →  .gba  →  模拟器/真机
   (.gbastudio)        scenario.txt     PowerShell       ROM
```

**没有重新实现任何编译逻辑**：中文点阵字库、素材转换、ARM 编译，全都还是原来那套 C 工具链。
编辑器只负责"把时间轴翻译成剧本"，然后调 `scripts/build-assets.ps1` 和 `build.ps1`。

---

## 二、样品工程

### 生成

```powershell
python tools\make_sample.py                 # 生成到 samples\魔女与少女
python tools\make_sample.py -o 别的目录 -n 别的名字
```

它会：建目录结构 → 从 `assets_src/images/` 拷真实素材 → **手动归类**（走的就是用户在界面上走的那条路）
→ 建角色表 → 排一条 13 个片段的时间轴 → 存成 `.gbastudio`。

### 里面有什么

| 轨道 | 内容 |
|---|---|
| 背景 | 海岸 → 沙漠（两次切换） |
| 立绘A | 魔女（left） |
| 立绘B | 少女（right，中途退场） |
| 台词 | 7 句（4 句对话 + 3 句旁白） |
| 资源库 | 4 个已归类 + 1 个故意留「未分类」（LOGO.png，演示未分类状态） |

刻意**没放**语音/音乐/特效片段 —— 当前引擎还不支持，编译器会如实报告跳过数量。

### 实测结果（本机）

```
合规检查        ✅ 没有发现问题
导出耗时        2.6 秒
ROM 大小        249.3 KB
字库            255 字 × 11×11（按新剧本重算）
```

## 三、编译器（`gbastudio/core/compiler.py`）

时间轴 → 剧本，输出两层：

1. **事件表**：给人看的中间格式，导出时写进日志面板
   ```
    0.00  背景    背景 → 海岸.png
    0.50  立绘A   显示 角色 witch（normal）
    1.00  台词    说话：魔女｜海风停了。
   ```
2. **scenario.txt**：现有 C 引擎认识的格式
   ```
   bg bg_ocean
   char left witch
   say 魔女|海风停了。
   hide right
   end
   ```

### 当前引擎的能力边界（编译器会如实报告）

| 元素 | 支持 | 说明 |
|---|---|---|
| 背景切换 | ✅ | 只认 海岸 / 沙漠 两张（v1 引擎内置），其他背景会提示"已跳过" |
| 立绘显示/隐藏 | ✅ | 只认 witch / girl 两个角色，位置 left / right |
| 台词 | ✅ | `say 名字\|内容`，名字空 = 旁白 |
| 语音 / BGM / 音效 / 特效 | ❌ | 统计数量后提示"等引擎升级" |

**位置只有 left/right**：因为 GBA 的 OBJ 层和模式 3 位图当前只实现了两个位置。
中间的 `center` 会被折到 left —— 这是引擎的局限，不是编辑器的。

### 写编译器时踩的两个坑（都是样品测试才暴露的）

1. **台词说话人丢了**：只给立绘片段解析了角色，台词片段忘了解析 → 输出 `say |海风停了。`
2. **隐藏动作不生效**：动作有时存在 `props['action']`（编辑器写的），有时存在 `kind`
   （生成的数据写的），只看一处会把"隐藏"当成"显示" → 输出两次 `char right girl`

两个都已经修好，并且**只有做样品跑通全链路才发现** —— 这就是"出个样品测试"的价值。

## 四、导出按钮做了什么（`ui/mainwindow.py` 的 `on_export`）

1. 编译当前项目 → 拿到剧本 + 提示列表
2. 把**事件表**写进日志面板（出问题直接看这个）
3. 有提示（比如"3 个语音片段被跳过"）会先弹窗确认
4. **后台线程**跑构建（界面不卡），日志实时流回面板
5. 成功后问"要打开模拟器试玩吗"

### 必须重跑 `build-assets.ps1` 的原因

中文字库是**按剧本里出现过的字**生成的。新写的台词会带进新汉字，
不重算字库的话那些字在屏幕上**直接空白**（不是乱码，是空白，很容易误判成显示 bug）。

实测：样品剧本 255 个字，字库 5,610 字节。

## 五、素材导入/归类（P2 改动）

- **导入不分类**：文件原样放进 `assets/`，标为「未分类」（黄色分组）
- **右键 →「归类为」**：背景 / 立绘（选角色）/ 音乐 / 语音 / 音效，也能改回未分类
- 归类结果**不会被重新扫描覆盖**
- 归类 = 把文件移进对应目录 + 记下类型

### 踩过的坑

- `shutil.copy2` 会**连只读属性一起复制**（源图来自只读的附件库），
  之后想删/改素材会 `PermissionError` → 改用 `shutil.copy` + `os.chmod`
- `tempfile.mkdtemp()` 建的目录在 Windows 上带受限 DACL，
  沙箱里的 Python 写不进去 → 测试/临时目录一律用工程内的 `.tmp`
