## 二、真实调度怎么拿到的

### 用户的解包工具里有一份完整的反汇编器

```
D:\GitHud\3DSStudio\tools\ws2_disasm.py      12 KB   ← 反汇编器本体
D:\GitHud\3DSStudio\tools\ws2ref\CLegacyFunctions.cs  52 KB ← 249 条指令的参数表
```

它是照着 `pkuislm/ws2Parse` + 那份 C# 参考实现的 ✓
解密是 **`rot_right2`（循环右移 2 位）** ✗ —— 不是减法也不是异或 ✓
（我先前自己试 `b-2` / `b^2` / UTF-16 全都对不上 ✓ 难怪 ✓）

### 反汇编出来的指令（`s0_01` 的真实片段）

```
(51, ['bg01', 'BGBLACK.PNG', 1, 1])      设图层图片 —— bg01 是底图 ★
(51, ['ev01', 'EV301_001M.PNG', 1, 1])   事件 CG / 立绘 ★
(70, ['bg01', 0, 0, x, y, ...])          图层位置/缩放
(101, [0, 0, 0.5, 0.0, 2, ''])           淡入 / 转场
(21, ['%LF刹那', 0])                     说话人 ★
(20, [index, 'char', '...', 0])          消息 —— index 与 TSV 行号**完全对应** ★★
(40, ['charSET', 'SET0040.OGG', ...])    语音文件 ★
(30, ['bgm01', 'NSBGM02.OGG', ...])      BGM
(7,  ['S0_03'])                          跳到下一场景 ★
```

**`20` 的 index 和 TSV 的行号一一对应** ✗ 这一条是整个方案成立的关键 ✓
所以只要**顺序扫一遍** ✗ 边走边记"当前底图是谁、当前立绘是谁" ✓
遇到 `20` 就把当时的状态记下来 ✓ 遇到 `40` 就记住这条消息的语音 ✓
得到的就是**真实的调度表** ✓✓

## 三、真实调度改变了什么

| | 合成填充（旧） | **真实调度（新）** |
|---|---|---|
| 每盘背景 | 143 张摊开 = 11 MB | **10~28 张 = 0.75~2.1 MB** |
| 语音挂法 | 顺序贴满 | **原作的每一条** |
| 说话人 | 无 | **有**（3213 条，中文名） |
| 图像占用 | 11 MB/盘 | **1~2 MB/盘** |

**图像占用掉到十分之一** ✗ → 于是卡带**几乎全被语音占满** ✓
所以"按章分盘"不够了 ✗ 得**按语音量分盘** ✓

## 六、怎么用

```powershell
# 1) 提取真实调度（用你自己的反汇编器）
python tools\ws2_scenes.py --rio "<解包>\剧本\Rio" --out .tmp\ws2_scenes.json

# 2) 按语音量自动拆盘构建
python tools\build_chapters.py `
    --src "<解包目录>" `
    --tsv "<解包>\剧本\台词对照_JP_CN.tsv" `
    --chapters s0,s1,s2 `
    --voice-cap 330

# 产出：nxs_s0p1.gba … nxs_s2p2.gba（6 个）
# 脚本会自动备份并还原引擎仓库里的"当前导出"
```

**单独做一盘**（手工控制）：

```powershell
# 剧本（带真实调度）
python tools\tsv_to_project.py --tsv "<对照表>" --out "<输出>" --name s1 --chapter s1 `
       --scenes-json .tmp\ws2_scenes.json --keep-assets
```

## 七、剩下的问题

1. **视频 / 3D 特效** ✗ 放弃（硬件不支持）
2. **立绘的图层合成** ✗ 原作是"底图 + 事件 CG + 特效遮罩"多层叠加 ✓
   GBA 只有一层背景 ✗ 现在是"取当前最主要的那张" ✓
   少数场景（背景 + 立绘同时要显示）会丢掉一层 ✓
3. **说话人 3213 / 5703** ✗ 旁白没有名字 ✓ 这是对的 ✓
4. **分盘的边界** ✗ 现在是在"语音序列"中间切的 ✓
   同一段剧情可能跨两盘 ✓ 要更好的体验可以调 `--voice-cap` 让切口落在章节边界 ✓
